# PDF 连续阅读布局优化

日期：2026-09-17。参考用户提供的连续阅读布局。

## 修改

- 有 PDF 时，将页码与缩放控件合入预览顶部一行，去除重复的 PDF 标题栏空间；窄面板允许工具栏换行。
- 外侧 padding 16px 改为 8px，适宽计算同步减去 16px 总边距；页间距 20px 改为 12px，减弱纸张阴影。
- 增加一键适宽，自动缩放模式显示实际百分比；保留整页与手动缩放。
- 布局偏好版本升级到 v3，首次读取旧 v2 时保留分栏、侧栏等设置，将缩放模式切为适宽。之后用户选择整页或自定义会正常保存，不重复重置。
- 新 PDF 提交前记录当前页与页内位置，在新文档布局提交后恢复；新 PDF 页数减少时限制到最后一页。
- 保留原有按 DPI 生成位图、单画布像素上限、邻近页渲染、失败保留旧 PDF 与 SyncTeX。没有通过放大低分辨率位图来冒充清晰度提升。
