## 实际结果

| 场景 | 结果 | 当前目标 | 结论 |
| --- | ---: | ---: | --- |
| 1000 文件树扫描 | 61.177 ms | 保持可操作 | 自动预算通过 |
| 1000 文件项目搜索 | 333.514 ms | 保持可操作 | 自动预算通过 |
| 普通文件打开 | 0.266 ms | 100 ms 内反馈 | 核心 I/O 预算通过 |
| 原子保存 | 10.046 ms | 500 ms 内完成（异常慢磁盘除外） | 核心 I/O 预算通过 |
| Release 整进程 smoke | 1377.48 / 1252.47 / 1262.27 ms | 冷启动到可交互 3 s | 仅证明热缓存整进程上界，不作为严格冷启动结论 |

整进程 smoke 包含应用确认页面就绪后的 250 ms 安全延迟，因此数值是保守上界；但连续运行可能命中系统文件缓存，不能冒充重启机器后的严格冷启动。文件打开和保存计时测量的是 Application/Adapter 核心路径，不等同于鼠标点击到屏幕绘制的 UI 延迟。

## 4 MiB 跨进程边界

`LightOverLeafRpcPayloadSmoke` 启动真实 CEF Browser/Renderer，以生产 RPC 保存并重新读取恰好 4 MiB UTF-8 文本，逐字节比较后关闭 Workspace。本轮最终测试耗时 1.62 秒，返回成功，进程专属临时目录已清理。该证据关闭 M4 的 4 MiB 真实跨进程遗留项。
