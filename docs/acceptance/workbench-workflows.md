# 工作台工作流拆分（2026-09-17）

## 本次实现

- useLocalWorkspace：本地编辑会话、文件 Revision、状态、互斥标志和卸载释放的统一所有者。
- useDocumentPersistence：保存、自动保存、磁盘刷新、变化轮询及延迟保存的协作流程。
- useConflictRecovery：对比请求、合并草稿、采用磁盘版本、另存副本及过期请求保护。
- useWorkspaceSwitch：打开/重开项目、准备编辑会话、切换提交与失败清理；通过生命周期回调通知界面，不直接操作弹窗或编译状态。
- ConflictForm：冲突处理展示独立于工作台组合层。

主组件从本轮开始时 983 行缩减到 707 行。跨工作流的本地会话和互斥标志保留一个所有者，不在各 hook 内建立平行副本。项目打开请求在卸载时取消；已过期的刷新轮询不能更新后续会话；旧对比请求不能清除新请求的忙碌状态。
