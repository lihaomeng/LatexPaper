# ADR 0007：本地文件管理与可恢复删除

状态：已实现，验收结果见 M4 增量记录。

Workspace 新增文件管理 Inbound 命令，经 Application 显式映射为独立 Outbound 命令。两套 DTO 都只依赖 Kernel，不让端口依赖 Domain 或相互依赖。原生工作流仅转发，RPC 仅校验并映射 `workspace.manageFile`。

第一版支持单个普通文件的空文件创建、重命名/移动和可恢复删除。父目录必须存在；不递归创建目录或删除目录。请求携带 Workspace ID，拒绝旧项目请求、非法相对路径、Windows 保留设备名和回收目录访问。文件修改在既有串行 Worker 执行。

Windows Adapter 使用 CREATE_NEW 防止覆盖。重命名从源文件句柄提交，ReplaceIfExists 为 false；源文件与祖先目录句柄限制删除共享，逐段拒绝 Reparse Point，减少目录替换竞态。所有句柄通过 RAII 回收，父目录锁有数量上限。成功提交之后的迟到停止不改变 Adapter 的成功结果。

删除将内容移入项目根 `.lightoverleaf-trash`，以随机标识加原文件名保存，保留正文。此目录从文件树扫描排除，普通管理 RPC 不允许操作它。用户可从资源管理器手动移回原目录，再重新打开项目刷新。当前不提供自动清空、自动恢复索引或永久删除。

Workspace 在操作前准备树快照，成功后提交相对路径变化，避免磁盘操作成功却因后续扫描失败而报告未执行。mutation-N 是当前会话的树状态标识，不是文档内容 Revision，也不表示外部文件变化已被监控。文件监视和完整刷新属于后续完善。

UI 在未保存/冲突时阻止管理操作，执行期间编辑器只读；成功后同步标签和文件树。目录管理、回收站管理界面、外部更改实时刷新、极端长路径和人工桌面验收仍待完成。
