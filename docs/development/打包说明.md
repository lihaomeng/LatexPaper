# 本地 EXE 打包

本脚本生成 Windows x64 开发版自解压 EXE，不是带卸载程序的安装向导。双击外层 EXE，选择目录解压，然后运行 LightOverLeaf/LightOverLeaf.exe。运行时必须保留同目录 DLL、platforms、locales、web 和其他资源。

## 一键打包

在仓库根目录的 PowerShell 执行：

```powershell
.\scripts\package.ps1
```

默认使用 desktop-release 配置并构建（构建包含前端检查），再执行 CTest、收集运行时和许可证、生成自解压文件、校验归档、解压并比较 SHA-256，最后启动解压目录中的程序执行 Smoke。

只重打包已有 Release：

```powershell
.\scripts\package.ps1 -SkipBuild
```

此参数仅跳过编译，不跳过 CTest 或解压验证。调用者负责确认既有二进制与源码一致。

7-Zip 默认路径为 C:/Program Files/7-Zip/7z.exe，可显式指定：

```powershell
.\scripts\package.ps1 -SevenZip 'D:\Tools\7-Zip\7z.exe'
```

该目录必须同时包含 7z.sfx 和 License.txt。脚本不会下载安装工具或 TeX。原生依赖沿用 CMakeCache 中的 Qt/CEF/MSVC 配置；当前 CRT 自动发现适用于现有 VS2019 布局。

## 输出

每次新建 out/packages/时间戳-随机标识/，不覆盖或删除旧包：

- LightOverLeaf-0.1.0-dev-win64.exe：自解压文件。
- 同名 .sha256：包校验值。
- package-report.json：所有验证通过后才生成的验收摘要。
- stage/LightOverLeaf：收集后的运行目录，含 manifest.json。
- verify/LightOverLeaf：实际解压并测试的运行目录。

失败时脚本抛出错误并保留现场；没有 package-report.json 的目录不可视为验收通过。stage 与 verify 占用额外磁盘空间，可以在确认不再需要证据后自行清理。

## 发布边界

这是按用户最新要求提前提供的开发版打包能力，不代表 M8 或编辑器功能全部完成。没有正式安装、升级、卸载、代码签名、快捷方式或文件关联；应用缓存仍写入 Windows 应用数据目录，不是完全便携用户配置。

附带本机依赖许可证和 Release CRT。外部分发前仍需完整第三方许可／源码提供义务核查、签名以及干净 Windows 10/11 验收；本机限制 PATH 的 Smoke 不能替代干净系统测试。当前不包含 TeX，文件保存、编译和 PDF 等未实现功能不会因打包而获得。
