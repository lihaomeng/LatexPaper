## 历史阶段：M2（未验收项保留）

### 已有成果

- 深色三栏布局、文件树、大纲、多标签和 Monaco 草稿编辑。
- 本地离线脚本、Monaco Worker 和字体打包；开发 Fake 与生产 CEF 通道分离。
- 草稿检查点串行写入、恢复和多窗口写入互斥；这些不是原生项目文件保存。
- 历史验证：前端 64 项测试、桌面 Debug／Release 各 11 项测试通过。具体环境、命令、范围及限制以 M2 验收记录为准。

### 修复前未通过项与所需决策（历史）

严格 CSP 仍阻止 Monaco 的内联样式属性，代码行发生重叠。已有随机 nonce 方案允许受控动态样式表，但未解决行定位属性；不得将“页面就绪”或测试通过当作视觉通过。

拟议修复需要用户明确允许仅增加 `style-src-attr 'unsafe-inline'`。这会降低样式属性注入防护；脚本限制、带 nonce 的样式表限制及桌面远程连接限制继续保留。此前该安全策略变更未获授权，本次“按阶段执行”不视为此项授权，因此尚未实施。

取得明确决策后，先完成 M2 修复及复验，再进入 M3。M2 剩余检查包括实际编辑器排版、中文输入、窗口缩放、离线 Worker／字体加载、浏览器独立测试及 CEF 桌面回归。PDF Worker 的实际接入与验收属于 M6，未接入前不声称已经验证。

### 授权后的当前状态

2026-09-11 用户明确回复“可以”。两处 CSP 已仅增加 `style-src-attr 'unsafe-inline'`，其余限制保留。新增安全回归测试，本次前端 65/65、桌面双配置构建及各 11/11 CTest 通过；浏览器 1600×1000 与 700×800 截图确认排版正常，中文草稿重载恢复通过。详见 M2 验收记录末尾。

授权阻塞已解除。M2 仍需 CEF 桌面实际视觉／中文 IME、Worker 执行及离线加载证据、查找和撤销重做复验。用户随后明确要求继续 M3，已据此调整当前阶段，未将 M2 增量修复记为完整阶段完成。
